# 下载器任务管理

自动读取 MoviePilot 设置中所有已启用的 qBittorrent 和 Transmission，在插件数据页按下载器管理任务。

## 功能

- 查看下载器连接状态和任务列表。
- 开始或暂停单个任务。
- 开启“允许全量操作”后，开始或暂停当前下载器的全部任务。
- 操作结果保存在插件数据中，并在数据页显示。

## 使用

1. 在插件配置中启用插件。
2. 如需全量操作，打开“允许全量操作”。
3. 打开插件数据页，在当前下载器区域执行单任务或全量操作。

## 范围

- 全量操作只作用于当前下载器，不跨下载器执行。
- 插件只开始或暂停任务，不删除任务和文件。
- 插件不保存下载器地址或账号，直接复用 MoviePilot 下载器设置。
