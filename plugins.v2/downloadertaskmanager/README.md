# 下载器定时任务

自动读取 MoviePilot 设置中所有已启用的 qBittorrent 和 Transmission，为每个下载器分别配置一次性开始和暂停时间。

## 功能

- 每个下载器独立设置“全部开始时间”和“全部暂停时间”。
- 开始时间只恢复已暂停且未完成的下载任务。
- 暂停时间只暂停下载中、排队、校验中或获取元数据的未完成任务。
- 已做种、进度 100%、错误和未知状态的任务不会被操作。
- 初始执行使用精确到计划时间的一次性调度。
- 成功后清空对应计划；失败保留计划，5 分钟后重试。
- 数据页只展示计划状态和执行结果，不展示种子列表。

## 使用

1. 在插件配置中启用插件。
2. 为需要操作的下载器填写开始和/或暂停时间。
3. 保存配置后，MoviePilot 会在指定时间直接触发对应计划。

## 范围

- 每个计划只执行一次，且只作用于对应下载器。
- 不展示种子明细，不提供手动任务操作。
- 插件只开始或暂停任务，不删除任务和文件。
- 插件不保存下载器地址或账号，直接复用 MoviePilot 下载器设置。
